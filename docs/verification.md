# Проверка практических №12

Дата: 23 октября 2026. Проверялся локальный сайт через HTTP в браузере Codex (Chromium).

## Выполненные проверки

- `python3 tests/check_site.py`: пять страниц, локальные ссылки/якоря/ресурсы, h1/title/viewport, уникальные id, label/for, alt.
- `node --check js/main.js`: синтаксис JavaScript без ошибок.
- `git diff --check`: ошибок пробелов нет.
- Пять страниц (`index`, `catalog`, `product`, `order`, `contacts`) на каждой ширине 360, 430, 768, 1024, 1440px — 25 сочетаний для этого проекта. Переполнение ширины документа не обнаружено; сломанных видимых изображений нет.
- Визуально просмотрены основные экраны и формы. Это не пиксельное сравнение всех 25 экранов.
- В журнале браузера во время проверки страниц JavaScript-ошибок не обнаружено.

## Пользовательские сценарии

Нативный dialog открывается на 360 и 1440px, целиком помещается в экран; фокус переходит в поле имени. Escape закрывает окно. Пустая форма выделяет пять обязательных полей; корректные учебные данные проходят проверку. Отдельная заявка принимает товар из ссылки. При новой попытке отправки прежний успех скрывается.

## Адаптивность

Hero выбирает `hero-mobile.webp` на 360/430px, `hero-tablet.webp` на 768/1024px и `hero-desktop.webp` на 1440px. Подтверждено через DOM `currentSrc` (не ручной снимок вкладки Network). WebP-варианты карточек имеют настоящие размеры 320/640/960px.

Таблица прокручивается внутри контейнера на 360/430px. На 768/1024/1440px локальная прокрутка не нужна. Bootstrap отсутствует; адаптивность реализована собственными min-width-медиазапросами.

## Ограничения

Отдельной сборки нет: это статические HTML/CSS/JS-проекты. Backend, реальная отправка форм, оплата и база данных не предусмотрены заданиями. Проверки Safari/Firefox, реальных телефонов, скринридера и Lighthouse не выполнялись. Полный аудит доступности относится к следующему занятию. Проверка не заменяет защиту и сдачу в СДО.
